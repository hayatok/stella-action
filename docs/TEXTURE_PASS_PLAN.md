# Stella テクスチャパス 実行仕様（v4）

作成: 2026-11-23 / 根拠: research_ref/REPORT.md の比較結果と、小浜の承認（2026-11-23 10:06 UTC「やってみよう！」）

## 目的

ポリゴン増量ではなくテクスチャで見た目を底上げする。比較で判明した最大の差は
テクスチャ有無（Unity-chan: 顔2048²、体・髪1024²＋法線／Stella v3: テクスチャゼロ、ベタ塗りのみ）。

## 前提・固定条件（AGENTS.md / 既存契約）

- アニメーションクリップ名は Idle / Run / Jump / Attack で固定、モデル規格（サイズ・+Z向き）は v1〜v3 と同一にし、ゲームコードは無変更で差し替え可能にすること。
- git のコミット・push・公開設定は行わない（人間側で実施）。
- テクスチャ生成は Codex の GPT imagegen を使う（自前生成で代替しない。生成物の出所＝Codexセッションフォルダとログを証跡として残すこと）。

## 作業ステップ

1. **UV展開の設計（Wonder / Blender Python）**
   - 対象パーツを優先順に: 顔（頭）→ 髪（ツインテール・前髪）→ ジャケット/服 → ブーツ・サッチェル。
   - v3 の make_stella_v3.py を土台に、各メッシュへ UV レイヤーを追加。球・チューブ系は継ぎ目位置を背面に寄せる。
   - まずは顔と髪だけの最小スコープで1周し、効果を確認してから服へ広げる。
2. **テクスチャ生成（Codex / GPT imagegen）**
   - 顔: 2048×2048 目安。虹彩グラデーション、まつ毛ライン、眉、口、チークを描き込み、UV配置に合わせた顔テクスチャ。
   - 髪: 1024×1024 目安。ティール色ベースに毛流れとハイライト帯（天使の輪）。
   - 服: 1024×1024 目安。ジッパー、縫い目、星パネル周りの陰影（ジオメトリ側の星は残す）。
   - 生成は「UVテンプレート画像を入力に、島の内側だけを描く」形で位置ずれを防ぐ。
3. **貼り付けと検証（Wonder）**
   - Principled BSDF にベースカラーを結線し GLB へ再エクスポート（public/models/stella.glb と同規格）。
   - v3 と同じ画角で比較レンダー（正面・顔アップ・3/4・背面）を作り、UVの伸び・継ぎ目・左右反転をチェック。
   - ゲーム内（ローカル）で Idle/Run/Jump/Attack の回帰確認。GLB容量の増加も報告（v3時点で12.4MB、読み込み重さに注意）。
4. **判断ポイント（小浜に聞くのはここだけ）**
   - 顔テクスチャのタッチが原画（art/stella-concept.png）と合っているか、1枚目の顔アップレンダーで確認してもらう。

## やらないこと

- スキニング/ボーン化（比較レポートのギャップ2）は今回のスコープ外。テクスチャの効果を見てから別途判断。
- 表情ブレンドシェイプも対象外（まばたき等の簡易対応も今回は入れない）。

## 成功条件

- テクスチャゼロ→顔・髪・服にテクスチャありになり、比較レンダーで「ベタ塗り感」が解消していること。
- ゲームコード無変更で差し替えでき、アニメーション回帰がないこと。
