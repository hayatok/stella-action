# ステラ・アクション（仮）― 設計書

三人称視点アクションのプロトタイプ。目的は開発パイプラインの検証:
GPT原画（Codex/imagegen）→ Blenderモデリング＋アニメーション（Muse）→ 実装（Codex）。

## 主人公「ステラ」
星屑航路の配達少女。原画: `art/stella-concept.png`（ティールのツインテール、星モチーフのクーリエジャケット、サッチェル、腰のエネルギーブレード）。
3Dモデル: `public/models/stella.glb`、アニメーションクリップ名は **Idle / Run / Jump / Attack**。

## 舞台
夕暮れの浮島アリーナ（円形、半径約25m）。周囲に岩とクリスタル、訓練ドローン3体が浮遊。

## 操作
- WASD / 矢印: 移動（カメラ基準）。キャラは移動方向を向く
- マウスドラッグ: カメラ回転（三人称、キャラ後方に追随）
- Shift: ダッシュ（速度1.6倍）
- Space: ジャンプ（Jumpクリップ）
- J キー / 左クリック: 攻撃（Attackクリップ、3回までコンボで少し前進）
- スマホ: 左半分バーチャルスティック、右側にジャンプ/攻撃ボタン（最低限）

## アニメーション状態遷移
- 静止: Idle（ループ）
- 移動中: Run（ループ、再生速度は移動速度に連動）
- 空中: Jump
- 攻撃中: Attack（0.45秒、移動入力を上書き、終了でIdle/Runへ）
- 状態が変わるたび 0.12 秒でクロスフェード

## 戦闘（プロトタイプ範囲）
- 訓練ドローン: HP 3。攻撃範囲（前方2.2m、扇形）に入っていればヒット
- ヒット時: ノックバック＋点滅＋ヒットストップ 60ms＋パーティクル
- 撃破時: 爆発パーティクルと星屑を落とす。全3体撃破で「CLEAR!」表示とリスタートボタン
- プレイヤーの被ダメージはなし（プロトタイプ）

## 技術
- Three.js（CDN不可、npm + vite、相対パス base './'）
- GLB読込失敗時はカプセル型ダミーにフォールバック（アニメなし、その旨を画面に小さく表示）
- 60fps目標、影は1灯のみ
