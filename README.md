# ステラ・アクション（仮）

美少女キャラの三人称アクション・プロトタイプ。
開発パイプライン: GPT原画（Codex / imagegen）→ Blenderモデリング＋アニメーション（Muse）→ 実装（Codex）。

- 設計書: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- 原画: `art/stella-concept.png`
- 操作: WASD 移動 / マウスドラッグ カメラ / Shift ダッシュ / Space ジャンプ / J or クリック 攻撃

## 開発

```bash
npm install
npm run dev
npm run build
```
